# AIMAN Implementation Roadmap

## Phase 0 — Foundation
Audit existing skeleton, freeze contracts, health checks, configuration, logging and migration baseline.

## Phase 1 — Brain
Intent, context builder, reasoning, planner and decision interfaces.

## Phase 2 — Model Router
Ollama adapter, provider abstraction, fallback policy and model telemetry.

## Phase 3 — Memory/RAG
Memory classification, document ingestion, pgvector retrieval and scoped knowledge.

## Phase 4 — Mission Engine
Durable missions, task graph, checkpoints, status transitions and resume.

## Phase 5 — Agents
Research, Developer, Designer and QA with Agent Manager and execution records.

## Phase 6 — Tools
Web/search, files, terminal, GitHub, browser and controlled computer execution.

## Phase 7 — Security
Permissions, approvals, secrets, audit and emergency stop.

## Phase 8 — Interfaces
Command Center, text/voice/WhatsApp adapters and notifications.

## Phase 9 — Business/Personal packs
CRM, content, sales, finance, support, calendar, email and automation integrations.

## Phase 10 — Oracle
Always-on backend/workers and secure remote operation.

## Phase 11 — Civilization
Isolated multi-agent simulation and organizational experiments.

## Build gate
Each phase requires tests and verification before the next phase is treated as stable. Existing functionality is preserved through incremental migrations.
