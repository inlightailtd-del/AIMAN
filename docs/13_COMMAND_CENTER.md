# AIMAN Command Center

## Purpose
Provide one control surface for missions, agents, memory, approvals, models, tools and system health.

## Main views
- Mission board
- Agent workforce
- Execution timeline
- Approvals
- Memory/knowledge
- Model/provider health
- Tool activity
- Errors and recovery
- Integrations
- System health
- Usage/cost where available
- AI Civilization sandbox

## Mission view
Show objective, plan, task progress, active agents, tool calls, blockers, verification and final artifacts.

## Agent view
Show agent version, status, current task, recent executions, failure rate, tool permissions and evaluation results.

## Approval view
Show exact action, risk, scope, evidence and approve/reject controls.

## Architecture rule
The dashboard is a control surface, not the system of record. AIMAN Core/backend remains authoritative.

## Future interfaces
Web dashboard first; voice, WhatsApp, mobile and browser interfaces call the same backend capabilities.
