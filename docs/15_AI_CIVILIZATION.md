# AIMAN AI Civilization Sandbox

## Purpose
A controlled simulation for experimenting with multi-agent organizations, jobs, companies, skills, markets and learning without giving simulated agents real-world authority.

## Entities
Citizens, skills, jobs, companies, contracts, virtual currency, resources, reputation, training programs, events and simulation rules.

## Loop
Observe -> decide -> act -> earn/spend virtual resources -> learn -> update state.

## AIMAN role
AIMAN can act as simulator administrator, create scenarios, assign work, evaluate agents, compare organizational structures and summarize outcomes.

## Isolation
No real bank accounts, production credentials, legal commitments, external publishing or physical controls. Integrations are disabled by default.

## Experiments
Test hiring models, specialization, incentives, cooperation, competition, learning rates and organizational structures.

## Evaluation
Measure task completion, resource efficiency, stability, collaboration, error rates and scenario-specific objectives.

## Reproducibility
Every simulation records seed/configuration, starting state, rules, model versions and events so experiments can be replayed and compared.
